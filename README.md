# Chess Scout

Find an opponent's Chess.com and Lichess accounts, then prepare for the round: opening report, board explorer,
engine suggestions, a prep sheet checked against your own games, and a practice drill against their real moves.

Runs entirely in the browser. It reads public game data from the Chess.com and Lichess APIs and uses Lichess's
cloud engine analysis. Nothing is stored on a server; saved opponents stay in your browser.

For pre-game preparation only. Outside help during an over-the-board game is not allowed under FIDE rules.
